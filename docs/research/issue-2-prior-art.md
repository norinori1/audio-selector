SAS is not suitable for direct reuse: a caller asking for Top-3 gets the retrieved subset sorted in the wrong direction, and simply reversing that subset does not fix ranking across the entire candidate pool. A thin proxy also cannot supply pre-retrieval license filtering through its current search endpoint. A bounded fork could fix these points, add manifest IDs and filters, and retain Gradio; the burden of maintaining the monolithic application is avoidable by wrapping its existing dependencies. The experiment does **not** claim the full UI or Qdrant server was deployed.

soundgrep's documented capabilities exist in separate components but should not be treated as a working complete product. Its indexer calls `insert_sample()` while DatabaseManager exposes `add_sample()`, and calls `add(sample_id, embedding)` while VectorIndex expects `add(embedding, sample_id)`. CLI indexing calls an absent `_conn()` and uses `duration` rather than schema `duration_sec`. These are architecture/integration issues, not reasons to build a new embedding/index engine.

Freesound can reduce online discovery work and supply candidate metadata. It cannot replace offline indexing of other sources. Use official API, quotas and app credentials, not scraping. Its hosted scores should not be mixed numerically with CLAP cosine without calibration. Original downloads require OAuth2; preview paths and original assets must be distinct in provenance. Service/commercial access terms and asset terms are separate review items.

PAM is interesting because its quality prompts need no reference recording. Its trained notion of clean audio could penalize intentional distortion, lo-fi noise or ominous drones. Adding another model/dependency stack without demonstrated reduction in audition cost is premature. Reuse standard DSP for duration, peak/RMS/loudness and decode failures; postpone learned quality weighting pending human correlation on game sounds. Do not substitute speech-only MOS tools or reference-dependent CDPAM as general no-reference SFX quality gates.

AudioCards suggests actor/action, acoustic descriptors and context fields; adopt a small verified subset as enrichment, with original metadata preserved. Generated captions must never author license facts. The companion release is metadata associated with separately licensed audio, not permission to download a professional library or evidence that all trained models are reusable OSS.

## Reuse dependencies and legal boundaries

Qdrant [server license](https://github.com/qdrant/qdrant/blob/master/LICENSE) and [client license](https://github.com/qdrant/qdrant-client/blob/master/LICENSE) are Apache-2.0; [FAISS](https://github.com/facebookresearch/faiss/blob/main/LICENSE) is MIT; [librosa](https://github.com/librosa/librosa/blob/main/LICENSE.md) is ISC; [SoundFile](https://github.com/bastibe/python-soundfile/blob/master/LICENSE) is BSD-3-Clause. These are reusable primitives, subject to their notices and transitive dependency terms. Qdrant is preferred for metadata filters; tested local mode is exact search suitable for this tiny experiment, and does not establish server HNSW performance. FAISS is an alternative if a later measurement justifies its separate eligibility layer.

No license label above approves commercial production use. Preserve MIT notices when copying/forking; retain Apache license/notice obligations when distributing applicable components; treat CC0 source, Apache/MS-PL model weights, training data, API agreement, preview files and exact final audio independently. Missing soundgrep/DCASE2025 grants require clarification before redistribution. No GPL/AGPL application is selected by this decision, but optional packages and bundled code need a concrete dependency inventory before distribution.

## Revised follow-up work

Only issues #1 and #2 existed at inspection; no existing implementation child issues need rewriting. Recommended backlog below replaces assumptions of building a new search engine. Keep #1's workstreams linked to the ADR when publishing this branch; no GitHub issue edits were made by the research scripts.

1. **Exact candidate manifest and evidence-backed license gate.** Hash original and preview separately; record source ID/URL, uploader, acquisition/license evidence, derivative lineage and policy decision. Unknown/incompatible candidates never enter eligible retrieval.
2. **Pinned LAION/Transformers + Qdrant adapter smoke test.** Fail closed without model, pin model revision and preprocessing, persist manifest IDs, enforce eligibility before Top-K, expose raw cosine. Validate Windows restart/reindex and score direction. No custom index/model.
3. **Human preference benchmark for SFX and BGM.** Small explicitly licensed real-world pilot, multiple relevant answers, blinded listening, Recall@K/mAP@K and audition time. Test negative descriptions, long-file segments and alternative music checkpoint; synthetic fixtures alone are insufficient.
4. **Game-role scoring and diversity composition.** Define role profiles separately from source evidence; retain semantic/DSP/role/diversity score breakdown; use existing reranking algorithms and evaluate duplicate/pack/source collapse.
5. **Audition queue using existing UI components.** Ordered preview, exact-source/license evidence, shortlist/reject and reproducible export. Evaluate a repaired SAS Gradio shell before designing a new UI stack.
6. **Optional Freesound API adapter.** Verify current endpoint, similarity-space contract, authorization/quotas/commercial terms; preserve original vs preview identity; no bulk download. PAM/AudioCards model evaluation remains conditional on measured need and clear terms.
